# Kuasai Matematik bersama Cigu Nofal

Aplikasi Android offline untuk latihan tambah berperingkat. Dibina ringan untuk telefon dan tablet Android, termasuk peranti lama.

## Ciri utama
- 60 jawapan betul untuk naik tahap
- Jawapan salah mengurangkan kemajuan tahap kepada separuh
- Tahap 6 digit + 6 digit tanpa had
- Akaun dan kemajuan disimpan pada peranti
- Tidak memerlukan internet
